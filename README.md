# 🎮 2048 Game

A classic **2048 puzzle game** built using HTML, CSS and JavaScript. Combine matching numbered tiles to increase your score and work towards reaching the **2048 tile**!

This project features a modern dark-themed interface, score tracking, achievements and browser-based progress saving.

## ✨ Features

- 🎯 **Classic 2048 Gameplay** – Combine matching tiles to reach 2048.
- 🏆 **Best Score Tracking** – Save your highest score using `localStorage`.
- 📊 **Game Statistics** – Track your current score, best score, moves and highest tile.
- 📈 **Progress Bar** – Monitor your progress towards the 2048 tile.
- 🥇 **Achievements System** – Unlock achievements by merging tiles and reaching milestones.
- 💾 **Saved Achievements** – Keep unlocked achievements after refreshing the page.
- 🎨 **Modern UI** – Dark-themed design with purple accents.
- ✨ **Tile Animations** – Animated appearance of newly generated tiles.
- 🔄 **Restart Game** – Start a new game without losing your best score.
- 🗑️ **Reset Best Score** – Clear your saved record when you want a fresh challenge.

## 🎮 How to Play

1. Open the game in your browser.
2. Use the **arrow keys** to move the tiles.
3. When two tiles with the same number collide, they merge into one.
4. Continue merging tiles to increase your score.
5. Try to create a **2048 tile**!
6. Unlock achievements as you progress.

## 🏅 Achievements

| Achievement | How to Unlock |
|---|---|
| ✨ First Merge | Merge two matching tiles |
| 🥉 Getting Started | Reach a 128 tile |
| ⭐ Halfway There | Reach a 1024 tile |
| 🏆 2048 Champion | Reach a 2048 tile |

Achievements are saved locally in your browser.

## 🚀 Getting Started

### Prerequisites

- A modern web browser such as Chrome, Edge or Firefox.
- Visual Studio Code (optional).
- Live Server extension (optional).

### Installation

## 🚀 Getting Started

### 📥 Download the Game

1. Open this GitHub repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file to a folder on your computer.

### ▶️ Run the Game Using Live Server

1. Open **Visual Studio Code**.
   
2. Select **File → Open Folder** and choose the extracted project folder.
   
3. Make sure you have the **Live Server** extension installed.
   
4. Open `2048.html` in VS Code.
   
5. Right-click the file and select **Open with Live Server**.
    
6. The game will automatically open in your default web browser.

🎮 **Start playing!** Use the arrow keys to move and merge tiles until you reach 2048.

### 🌐 Alternative: Run Without Live Server

You can also double-click `index.html` in the extracted folder to open the game directly in your web browser. No additional installation is required.

The game uses the browser's `localStorage` to save:

- Your unlocked achievements.

Saved information is stored locally in your browser and does not require an account or database.
